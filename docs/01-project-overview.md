# Labour Marketplace

## Project Description

Labour Marketplace is a platform connecting employers with nearby skilled workers such as electricians, plumbers, painters, carpenters, drivers, and other daily wage professionals.

The platform allows workers to create profiles, showcase their skills, set their rates, and receive job requests.

Employers can search for nearby workers based on profession, location, rating, and availability.

## Problem Statement

Finding trusted local workers is difficult and often relies on personal references.

Workers struggle to find consistent work opportunities.

This platform aims to bridge the gap between workers and employers through a location-based marketplace.

## Target Users

1. Workers

   * Electricians
   * Plumbers
   * Painters
   * Carpenters
   * Drivers

2. Employers
