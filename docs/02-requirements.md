# Functional Requirements

## Worker

* Register account
* Login
* Update profile
* Add skills
* Set hourly rate
* Upload profile image
* Update availability
* Accept jobs
* Reject jobs
* View ratings

## Employer

* Register account
* Login
* Search workers
* Filter by skill
* Filter by pincode
* View worker profile
* Book worker
* Rate worker

## Admin

* Manage users
* Manage workers
* Manage jobs
* Manage reviews

# Non Functional Requirements

* Mobile Friendly
* Fast Loading
* Secure Authentication
* Responsive Design
* Scalable Architecture
